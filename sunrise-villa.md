## Location

Băile Felix is Romania's largest and most popular thermal spa resort.

### Lacul cu Nuferi (Water Lily Lake)

Worth prominent mention on the website. Free entry, 100,000+ visitors/year, unique in Europe.

- Nufărul Termal (Nymphaea lotus var. Thermalis) - natural monument since 1931, Tertiary-era relic, unique to this region
- Nufărul Alb (White Water Lily) - blooms year-round
- Lotusul Sacru (Sacred Lotus) - pink flowers, June-August only
- Chiparosul de Baltă (Bald Cypress)

Water lilies open during the day, close at evening. Lotus only June-August.

### Email Flow

**Direct email to contact@**: Lands in ClausWeb mailbox → Gmail pulls via POP3 → Cristina sees in Gmail with "Sunrise Villa" label → replies as contact@

**Contact form submission**: Form plugin sends notification via GoSMTP from contact@ to contact@ → Gmail pulls via POP3 → Cristina replies → Reply-To header sends reply to customer directly

### Gmail Configuration

- Accounts and Import > "Check mail from other accounts": contact@sunrisevilla-felix.com via POP3 (mail.sunrisevilla-felix.com, port 995, SSL)
- Accounts and Import > "Send mail as": contact@sunrisevilla-felix.com via SMTP (mail.sunrisevilla-felix.com, port 465, SSL)
- "Reply from the same address the message was sent to" enabled
- Gmail filter auto-labels incoming business mail as "Sunrise Villa"

### Notes

- ClausWeb blocks email forwarding to Gmail/Yahoo/Outlook (anti-spam policy)
- Gmail POP3 polling interval is not configurable; frequency increases with mail volume
- "Check mail now" button in Gmail settings forces immediate pull
- WordPress admin email set to contact@sunrisevilla-felix.com

### Notes on SVG icons
Lucide icons are stroke-based and distort when scaled up in the Icon Block. Either use fill-based SVG sources directly, or flatten strokes to fills in Inkscape/Figma before pasting.

### WordPress subdirectory setup
WordPress is installed in /wp. Root public_html has an index.php that points to /wp/wp-blog-header.php. Site Address is set to the root domain without /wp. Do not change the WordPress Address.

## Backup & Versioning

- BackupPly Pro → Google Drive, daily automated backups, both files and DB
- Staging environment at staging.sunrisevilla-felix.com via Softaculous
- Child theme CSS versioned in Git (local + GitHub)
- Always backup before updates; update one plugin at a time
- Test a restore before site handoff

### Development Workflow

- Small CSS/content changes: push directly to prod
- Structural changes, plugin updates, new features: staging first, test, then push to prod via Softaculous
- Softaculous "Push to Live": prefer files-only push to avoid overwriting client content edits in database
- Always backup prod before pushing from staging
